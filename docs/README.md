# EduTrack - Startup EdTech

Plataforma web educativa para profesionales de tecnología en Latinoamérica.

## 🚀 Fase 1: Landing Page & Prototipo
- **Tecnologías:** HTML5, CSS3 (Variables, Flexbox, Grid), JavaScript Vanilla.
- **Arquitectura:** CSS Modular (Base, Layout, Components).

## 📁 Estructura de Carpetas
- `/src`: Código fuente de la aplicación.
- `/docs`: Documentación técnica.

## 🛠️ Características Implementadas
- Diseño Responsive (Mobile First).
- Sistema de filtros de cursos en tiempo real.
- Modales nativos con la API `<dialog>`.
- Botón de contacto directo a WhatsApp.
- Validación de formularios de autenticación.
